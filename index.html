How to Use

1. Launching Games

Tap the Gamepad menu icon at the top left to open the Games Library. Tap any game button to launch immediately into the full-screen edge-to-edge experience.

2. Returning to Dashboard

Every game view features a native Android return back arrow at the top-left corner. Tapping this cleanly stops the active game session, updates your score, and returns you directly to the menu.

3. True Offline Support

This web application utilizes an active Service Worker. After your first visit, all games, databases, and sound synthesis operate completely offline without requiring internet data.
